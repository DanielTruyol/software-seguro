### Objetivo 1: Puertos y Servicios Esenciales

| Puerto | Protocolo / Servicio | Capa de Transporte | Descripción y Función Principal | Nivel de Riesgo / Consideración de Seguridad |
| :---: | :--- | :---: | :--- | :--- |
| **20** | **FTP-Data** *(File Transfer Protocol)* | TCP | Canal de datos de FTP. Utilizado en el modo activo para transferir físicamente el contenido de los archivos entre cliente y servidor. | **Alto:** Tráfico en texto plano. Se recomienda reemplazar por SFTP (SSH) o FTPS. |
| **21** | **FTP-Control** *(File Transfer Protocol)* | TCP | Canal de control de FTP. Se encarga de enviar comandos (autenticación, cambio de directorio, listado de archivos) e iniciar la sesión. | **Alto:** Las credenciales y comandos viajan sin cifrar por la red. Vulnerable a ataques *Sniffing*. |
| **22** | **SSH** *(Secure Shell)* | TCP | Acceso remoto seguro a la consola de comandos (*shell*) y transferencia segura de archivos (SFTP/SCP) mediante canales cifrados. | **Bajo (Si se asegura):** Reemplazo seguro de Telnet. Debe protegerse desactivando acceso `root` y usando claves públicas. |
| **23** | **Telnet** | TCP | Protocolo legacy de administración remota por línea de comandos. | **Crítico:** Desactualizado y obsoleto. Todo el tráfico (incluidas contraseñas) viaja en texto plano. Usar SSH obligatoriamente. |
| **25** | **SMTP** *(Simple Mail Transfer Protocol)* | TCP | Transferencia y enrutamiento de correo electrónico entre servidores de correo (*MTA*). | **Medio:** Vulnerable a *Open Relay* y *Email Spoofing* si no se configuran adecuadamente SPF, DKIM y DMARC. |
| **53** | **DNS** *(Domain Name System)* | UDP / TCP | Traducción de nombres de dominio comprensibles para humanos (`ejemplo.com`) a direcciones IP numéricas (`192.0.2.1`). Usa UDP para consultas estándar y TCP para transferencias de zona. | **Medio/Alto:** Objetivo común para ataques de denegación de servicio (DDoS Amplification), *DNS Spoofing* y *Cache Poisoning*. |
| **80** | **HTTP** *(Hypertext Transfer Protocol)* | TCP | Servicio de transferencia de hipertexto utilizado para servir páginas web no seguras en la World Wide Web. | **Alto:** Los datos de formulario, cookies de sesión y peticiones no van cifrados. Se debe redirigir todo el tráfico a HTTPS (443). |
| **110** | **POP3** *(Post Office Protocol v3)* | TCP | Recuperación y descarga de correos electrónicos desde un servidor remoto al cliente local (generalmente eliminando el correo del servidor). | **Alto:** Transmite usuarios y contraseñas sin cifrar. Debe utilizarse POP3S (puerto 995) o IMAP/IMAPS. |
| **443** | **HTTPS** *(HTTP Secure)* | TCP | Protocolo HTTP sobre capa de cifrado TLS/SSL. Garantiza confidencialidad, integridad y autenticidad en la comunicación web. | **Bajo:** Estándar actual de seguridad web. Previene ataques de intercepción en tránsito (*Man-in-the-Middle*). |
| **3306** | **MySQL / MariaDB** | TCP | Puerto por defecto para el motor de base de datos relacional MySQL y MariaDB. | **Alto si se expone a Internet:** Nunca debe exponerse públicamente. Debe escuchar solo en `localhost` (`127.0.0.1`) o accederse vía VPN/túnel SSH. |
